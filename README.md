# 🚀 AutoTrainerStudio
Auto Trainer: Interactive No-Code Machine Learning Platform
Auto Trainer is a web-based, no-code platform built with Streamlit, designed to simplify the machine learning workflow and data analysis for users of all skill levels. This platform bridges the gap between data and decision-making by eliminating the need for coding expertise. Whether you're a beginner or a non-technical professional, Auto Trainer opens the door to data-driven innovation.

🧹 Preprocess data effortlessly

🤖 Train and evaluate machine learning models

📊 Visualize insights through interactive dashboards
